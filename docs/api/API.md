# API Reference

| Method | Endpoint | Purpose |
|---|---|---|
| GET | /api/bills/current.php?meter= | Current bill by meter number (used by fetch()) |
| GET | /api/bills/history.php | Previous bills |
| POST | /api/payments/create.php | Make payment |
| GET | /api/payments/status.php | Payment status |
| GET | /api/payments/receipt.php | Payment receipt |
| GET | /api/transactions/history.php | Transaction history |
